# Arcue icon

The approved source is `arcue-master.png`: the Diagonal lift image with the final Y-axis angle and balanced bands. Keep this master for future exports. These files preserve its colors, framing, and background.

| File | Use |
| --- | --- |
| `arcue-master.png` | Original 1254 × 1254 image |
| `arcue.png` | 1024 × 1024 app or website image |
| `arcue.webp` | Lossless 1024 × 1024 web image |
| `arcue.icns` | macOS app icon, standard and Retina sizes |
| `arcue.ico` | Windows app icon, 16–256 pixels |
| `favicon.ico` | Browser favicon, 16, 32, and 48 pixels |
| `png/arcue-*.png` | Individual 16–1024 pixel exports |

Run `pnpm icons` to regenerate every format and refresh the web host's favicon and home-screen icons. The master is raster artwork; these exports do not claim to be a vector logo.
