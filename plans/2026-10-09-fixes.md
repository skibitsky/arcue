# Arcue audit fixes and verification

Implemented all 11 ranked findings, the deferred picking-cache defect D01, and the reported development dependency maintenance from the [audit](2026-10-09-codebase-audit.md). Three implementation sub-agents worked in separate file scopes, with coordinating integration and review. Changes were prepared on the existing branch, based on `1d54da8`; no worktree, branch, deployment or sample/WASM regeneration was created.

The work used vertical TDD cycles: a failing behavior regression, a minimal fix, then a passing focused run before the next behavior. The new spatial-index API began with failing public-interface tests; exact-equivalence and deterministic work-reduction regressions verify its behavior. Dependency maintenance used a failing package audit followed by a clean audit as its gate.

## Performance measurement

On this host with Node 26.7.0, 10,000 exact nearest-vertex queries over a 100,000-vertex mesh took approximately **1,024 ms with the prior full scan versus 111 ms including the new index build**. Reusing the index reduced the query portion to about 10 ms. This is a local synthetic benchmark, not an end-to-end reload guarantee. The committed regression checks coordinate-read reduction and exact results without a fragile timing threshold.

A final RED→GREEN follow-up caught index construction overhead for tiny regions: one saved position over 4,096 destination vertices initially incurred 517,307 coordinate reads. Regions below 128 saved positions now use the direct scan unless a cached index is already available. Separate regressions protect both the tiny-region cost and reuse after a large region.

## Compatibility and remaining boundaries

- Old saved reviews, short version references and historical round files continue to load. New internal IDs are full-length; displayed prompt versions remain short.
- Automatic member recovery now intentionally ends prior undo/redo history, rather than allowing that history to restore obsolete identifiers.
- On case-sensitive filesystems, creating a previously missing texture with different filename or directory casing can require explicit Reload. Reload uses the existing case-insensitive search; automatic watchers still subscribe to exact paths.
- Path checks reject replaced links before reads/writes/rollback. They do not claim OS-level race resistance against a precisely timed concurrent filesystem attacker. Content hashes remain noncryptographic identities.
- Tests ran on this macOS host with Node 26.7.0. The broader real-export corpus, native parser fuzzing, Windows host behavior and other GPU/driver combinations were not tested in this repair run.
