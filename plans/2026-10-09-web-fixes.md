# Web drop and dependency fixes

Implemented A08 and development dependency maintenance from the codebase audit using failing gates before implementation.

## A08 Repeated and overlapping drops

The browser regression `adds a model after replacing a pending drop with the same file` failed before the implementation: the composed parts remained `["PebbleGolem"]`, without `RepeatedCrate.fbx//Crate`. After making discard completion awaitable and cleaning up the old drop before staging its replacement, the same browser test passed.

Three additional vertical regression cycles covered related lifetimes:

- Closing a tab while its files were being placed initially recreated a prompt for the closed tab. Checking the original session after placement now discards those files; the regression passes.
- An earlier delayed placement initially overwrote a newer prompt. Serializing drop operations now preserves arrival order and cleans up the superseded files; the regression passes.
- An image dropped after a pending model initially left the old model prompt open. Applying replacement cleanup before either kind of drop now dismisses it; the regression passes.

Focused verification: all 44 tests in `view-files.test.ts` and `Workspace.test.tsx` passed after these changes. Full combined validation is recorded in the consolidated fix report.

## Development dependencies

The initial `pnpm audit --json` gate reported 11 advisories: three high, five moderate, three low, all in Wrangler's Miniflare dependency chain. Registry metadata confirmed Wrangler 4.149.0 depends on Miniflare 5.20261006.1-alpha with patched Undici 7.29.1 and sharp 0.35.5.

Updated the workspace catalog from Wrangler 4.139.0 to 4.149.0 and regenerated the lockfile with `pnpm install --ignore-scripts`. The updated full audit passes with zero advisories. This used the package audit as its red/green gate instead of adding an artificial application unit test for a third-party vulnerability.
